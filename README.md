# Bioinformatics Analysis Scripts

This repository contains R scripts used for the bioinformatics and statistical analyses described in the associated study.

## Contents

The scripts cover the following analyses:

- Differential expression and functional enrichment analysis
- Immune cell ssGSEA analysis
- Gene–immune cell correlation analysis
- Key gene correlation and GSEA
- Clinical variable analysis
- Logistic regression analysis
- Nomogram construction and evaluation
- ROC and calibration curve analysis

## Requirements

R (≥ 4.0) with the following packages:

- Seurat
- tidyverse
- dplyr
- ggplot2
- psych
- pheatmap
- clusterProfiler
- enrichplot
- rms
- pROC
- regplot
- GseaVis

Additional packages may be required for individual scripts.

## Data

Input data and file paths are represented by placeholder variables in the scripts. Users should replace these placeholders with the corresponding local file paths and datasets.

## Reproducibility

The scripts provide the analysis procedures and parameters used in the study. Random seeds and package versions should be specified where necessary to reproduce the results exactly.
